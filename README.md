# Typing Practice Game

A simple typing game created to help players improve their typing speed and accuracy through practice.

## Overview

The Typing Practice Game displays words or sentences on the screen. Players must type the text correctly within a limited time. The game tracks accuracy and typing speed to help users measure their improvement.

## Features

- Typing practice with words or sentences
- Real-time input checking
- Speed (WPM) and accuracy tracking
- Increasing difficulty
- Clean and simple UI

## How to Play

1. Launch the game.
2. A word or sentence appears on the screen.
3. Type the text exactly as shown.
4. Submit your input by pressing **Enter**.
5. The game continues until time runs out or the game ends.

## Scoring

- Correct inputs increase score
- Incorrect inputs reduce accuracy
- Typing speed is measured in Words Per Minute (WPM)
